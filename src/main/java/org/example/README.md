 Hospital Notification System

Project Description
This is a Spring Boot application that demonstrates Spring IoC, Dependency Injection, and environment variable configuration.

 Features
- Email notification service.
- SMS notification service.
- Emergency notification service.
- Dependency Injection using `@Autowired`.
- Default service selection using `@Primary`.
- Specific service selection using `@Qualifier`.
- Configuration using `@Value`.

 Technologies
- Java
- Spring Boot
- Maven
- Git and GitHub

 Environment Configuration

Create a `.env` file with:

```env
HOSPITAL_API_SECRET=your_secret_key
HOSPITAL_NAME=Your_Hospital_Name
```

Never upload your `.env` file to GitHub.

Use `.env.example` as a template.

 How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure your environment variables.
4. Run `Smart HospitalApplication.java`.
